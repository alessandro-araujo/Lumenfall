# Lumenfall

Jogo 2D de aventura com elementos de RPG, desenvolvido iterativamente com Godot 4.x e GDScript.

## Estado atual

Projeto inicializado. Ainda nao existem cenas, mecanicas ou escopo definitivo.

## Fluxo de branches

- `master`: versao de producao, estavel e protegida.
- `develop`: versao integrada e segura para desenvolvimento.
- `release`: ciclo de preparacao da proxima entrega, sujeito a bugs e validacao.

O repositorio remoto devera ser privado. A protecao de `master` sera configurada no provedor Git quando o repositorio for publicado.
